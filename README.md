## What it demonstrates

- Custom `UITableView` section headers with an action button
- Showing and hiding the rows in a section by inserting and deleting them
- A button title that changes with the section's state ("Show more" / "Show less")
- A simple, dummy data source that keeps the pattern easy to reuse

## Running it

Open `WidgetSample.xcodeproj` in Xcode and run on a simulator. Tap a section's button to expand or collapse it.
